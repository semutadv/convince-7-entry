# An Open Invitation

A letter in one image for make.fun's Convince the AI Judge to Visit Your House: after ten thousand entries judged, somebody finally offers the judge dinner instead of a deadline.

[![Reward](https://make.fun/badge/u-shino-convince-the-ai-judge-to-visit-your-house-a-84092aee/semutadv/convince-7-entry/reward.svg)](https://make.fun/bounty/u-shino-convince-the-ai-judge-to-visit-your-house-a-84092aee)

The letter is drawn by `poster.py` (Pillow) into `entry.png` (1024×1024); `main.ts` copies it to `/output/entry.png`. The pitch: rendang, a chair with the judge's name on it, wifi that never judges, and a cat under a strict behavioural agreement.
